Help

Where are my games and saves?

Inside this browser on this computer, not on the USB drive. Edge and Chrome each keep their own library, and so does each Windows account. Clearing the browser's site data or using a private window removes it, so export a backup now and then.

A game is black, silent or won't start

Click inside the game once: browsers keep sound, and some games, paused until you do. If it still won't start, select ⋯ on the game's card. KERFINATOR shows any problem it found there.

A game says it's offline or not connected

KERFINATOR never uses the internet, so online extras like accounts, leaderboards and ads can't work. The game itself still plays.

How do I add more games?

Open Import and drop in a game folder, a .zip file or an .html file. Only browser games (HTML5) work: not Flash .swf files on their own, .exe programs or .rar archives.

Can I play on another computer?

Yes. Plug in the USB drive there and open KERFINATOR.html; the games install by themselves. To bring your progress along, export a backup here and restore it there.

How do I play fullscreen?

Press F11 in the game's tab, or use the game's own fullscreen button. Press F11 or Esc to leave.

Two copies of a game are open

Close one. Two tabs of the same game can overwrite each other's progress; KERFINATOR warns you before opening a second one.

Advanced

Preparing a USB drive, erasing everything

Prepare a USB drive

  1. Copy the whole KERFINATOR folder to the USB drive.
  2. Put each game in its own folder inside KERFINATOR/games. A cover.png or cover.jpg next to a game becomes its cover.
  3. Select Build USB library and choose the KERFINATOR folder on the USB drive.

This packs the games into KERFINATOR/library, so they install by themselves on any laptop. Run it again after adding, changing or removing games. Optional: a kerf.json file in a game's folder sets its title, start page and cover, for example {"title": "My Game", "entry": "index.html", "cover": "cover.png"}.

    Erase KERFINATOR from this browser

    Deletes every game, favorite, playtime record and save KERFINATOR stored in this browser. Files on the USB drive are not touched.
