Storage on this computer

Your games, favorites, playtime and saves live inside this browser on this computer, not on the USB drive. Other browsers and other Windows accounts have their own separate library.

Play without the USB drive

Save a copy of KERFINATOR to this computer (for example your Desktop). Open that copy next time: it shows the same library, even with the USB unplugged.

USB library

KERFINATOR was opened from a copy without a USB library.

Backup and restore

A backup holds favorites, playtime, custom titles and covers, and every game's save data. It doesn't include the game files: re-import those, or install them again from the USB.

Prepare a USB drive

  1. Copy the whole KERFINATOR folder to the USB drive.
  2. Put each game in its own folder inside KERFINATOR/games.
  3. Select Build USB library and choose the KERFINATOR folder on the USB.

Building packs every game into KERFINATOR/library so that, on any laptop, KERFINATOR installs them automatically with no clicks. Run it again whenever you add, change or remove games. Optional: a kerf.json file in a game folder sets its title, start page and cover, for example {"title": "My Game", "entry": "index.html", "cover": "cover.png"}.

    Good to know

    • Works offline in Microsoft Edge, Google Chrome and other Chromium browsers. No installation, no admin rights, nothing leaves this computer.
    • Clearing the browser's site data, or using a private/guest window, deletes the library. Keep a backup.
    • A few games need web-server-only features (such as multi-threaded Godot 4 or Unity builds) or online services. KERFINATOR tells you when a game hits one of these limits.
    • Games run in their own tab. Press F11 for fullscreen or use the game's own fullscreen button.

    Erase KERFINATOR from this browser

    Deletes every game, favorite, playtime record and save stored by KERFINATOR in this browser. Files on the USB drive are not touched.
